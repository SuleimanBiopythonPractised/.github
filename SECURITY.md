# Security Policy

## Supported Versions

Security updates are applied to the active repositories under the SuleimanBiopythonPractised organization:

| Repository | Supported |
| --- | --- |
| `SuleimanBiopythonPractised` | :white_check_mark: |
| `SuleimanBiopythonPractised.github.io` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within any repository in the SuleimanBiopythonPractised organization, please do **NOT** open a public issue.

Instead, please send an email to:
**suleyman.hacizade1@gmail.com**

Please include:
* Description of the vulnerability.
* Steps to reproduce or proof of concept.
* Impact assessment.

We take all security reports seriously and will acknowledge receipt within 48 hours.
