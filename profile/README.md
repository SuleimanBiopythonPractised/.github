## 📦 Repositories Overview

### 1. 🔒 [`SuleimanBiopythonPractised`](https://github.com/SuleimanBiopythonPractised/SuleimanBiopythonPractised)
> **Role**: Core Computational Biology Engine, Research Datasets, Statistical Modeling & Backend Workflows.  
> **Visibility**: 🔒 **Private** (Giriş üçün elektron poçtla müraciət edin: `suleyman.hacizade1@gmail.com` / Apply for access via email)

* **Key Capabilities**:
  * **Sequence Analysis**: Automated FASTA/FASTQ quality analysis, transcription/translation pipelines, ORF discovery, codon usage bias calculations.
  * **Dynamic Sequence Alignment**: Custom Needleman-Wunsch global alignment, Smith-Waterman local alignment with affine gap penalty modeling.
  * **Biostatistics & ANOVA**: Comprehensive experimental statistical analysis covering One-Way, Two-Way, and Factorial ANOVA with `statsmodels` and `pingouin`, complete with Tukey HSD post-hoc tests and diagnostic residual plots.
  * **Structural Bioinformatics**: Automated PDB/mmCIF structure retrieval, dihedral angle computation, and macromolecular contact mapping.
  * **Knowledge Engine**: Integrated Obsidian + LLM Knowledge Graph and research wiki for computational biology notes.
* **Stack**: Python 3.11+, Biopython 1.83+, NumPy, SciPy, Pandas, Statsmodels, Pingouin, Matplotlib, Seaborn, JupyterLab.

---

### 2. 🌐 [`SuleimanBiopythonPractised.github.io`](https://github.com/SuleimanBiopythonPractised/SuleimanBiopythonPractised.github.io)
> **Role**: Public-Facing Interactive Web Portal, Analytical Studio & GitHub Pages Host.  
> **Visibility**: Public  
> **Live Site**: **[https://suleimanbiopythonpractised.github.io/](https://suleimanbiopythonpractised.github.io/)**

* **Key Interactive Features**:
  * **🧬 Live Sequence Studio**: Real-time mRNA transcription ($T \to U$), reverse complementation, translation, molecular weight, GC/AT ratio, and melting temperature ($T_m$) calculators.
  * **⚡ Interactive Pairwise Aligner**: Client-side execution of dynamic programming sequence alignments with interactive scoring matrix visualization.
  * **📊 Biostatistics ANOVA Laboratory**: Interactive 4-cohort pharmacological trial simulation, real-time derivation of $SS$, $MS$, $F$-ratio, $p$-value, effect size ($\eta^2$), dynamic SVG boxplots, and Tukey HSD contrasts.
  * **🔬 3D Biomolecular Structure Viewer**: WebGL-powered 3Dmol.js molecular visualization supporting ribbon, cartoon, surface, and stick representations for standard PDB structures (Insulin, Crambin, Plant Lectin, etc.).
  * **📚 Curriculum & Notebooks Directory**: Searchable, categorized curriculum spanning 18+ computational biology training modules.
* **Stack**: HTML5, Modern Vanilla/ES6 JavaScript, Tailwind CSS, 3Dmol.js, FontAwesome, GitHub Pages CDN.

## 🛠️ Local Development Environment

On the developer workstation, both repositories are maintained locally side-by-side:
```bash
# Developer local workspace layout
/Users/macbookairm2/Documents/GitHub/
├── SuleimanBiopythonPractised/             # Backend & Data repo (git remote: private)
└── SuleimanBiopythonPractised.github.io/    # Frontend Web repo (git remote: public)
```

To clone and work with these repositories:

```bash
# 1. Clone the core backend repository
git clone https://github.com/SuleimanBiopythonPractised/SuleimanBiopythonPractised.git
cd SuleimanBiopythonPractised
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. Clone the frontend web portal
cd ..
git clone https://github.com/SuleimanBiopythonPractised/SuleimanBiopythonPractised.github.io.git
cd SuleimanBiopythonPractised.github.io
# Open index.html in any modern browser or run a local HTTP server:
python3 -m http.server 8000
```
