# Contributing Guidelines

Thank you for your interest in contributing to the **SuleimanBiopythonPractised** organization!

## Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started
1. **Explore the Repositories**:
   - [`SuleimanBiopythonPractised`](https://github.com/SuleimanBiopythonPractised/SuleimanBiopythonPractised): Python workflows, biostatistics notebooks, structural modeling.
   - [`SuleimanBiopythonPractised.github.io`](https://github.com/SuleimanBiopythonPractised/SuleimanBiopythonPractised.github.io): Interactive web client, 3Dmol.js viewer, sequence tools.
2. **Fork and Branch**:
   - Fork the repository.
   - Create a feature branch: `git checkout -b feature/my-new-feature`
3. **Coding Standards**:
   - Python code must follow PEP 8 formatting (`black`, `flake8`).
   - Web frontend code should use modern, accessible semantic HTML5 and vanilla JavaScript.
4. **Submitting Changes**:
   - Commit with descriptive commit messages.
   - Push to your branch and submit a Pull Request.
